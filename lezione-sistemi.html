Matematica

I sistemi
di disequazioni

x² − 4 < 0
x − 1x + 3 ≥ 0

Alla fine della lezione sapremo risolvere questo.

Le parti della lezione

    Ripasso · parte 1

    Disequazioni di 1° grado

    Si risolvono come le equazioni.

    3x − 6 > 0 → 3x > 6 → x > 2

    Moltiplico o divido per un numero negativo?
    Il verso si gira: > diventa <.

    −2x > 6 → x < −3

    Divido per −2. Il −2 è negativo: giro il verso.

    Perché si gira?

    5 > 3

    Moltiplico tutti e due per −1:

    −5 < −3

    −5 è più a sinistra di −3. È più piccolo.

    Ripasso · parte 1

    Quiz veloce

    −4x > 8

    5x ≤ 15

    3 − x < 2

    Ripasso · parte 2

    Disequazioni di 2° grado: la parabola

    Ogni espressione di 2° grado ha un disegno: la parabola.

    x² − x − 6

    > 0 vuol dire sopra

    Dove la parabola sta sopra l'asse x.

    < 0 vuol dire sotto

    Dove la parabola sta sotto l'asse x.

    I punti dove la parabola tocca l'asse sono le soluzioni dell'equazione x² − x − 6 = 0.

    Ripasso · parte 2

    Disequazioni di 2° grado: il metodo

    1. Porto tutto a sinistra. A destra resta 0.
    2. Il numero davanti a x² è negativo?
      Moltiplico tutto per −1 e giro il verso.
      Così la parabola è sempre aperta verso l'alto, come una U.
    3. Risolvo l'equazione ax² + bx + c = 0.
      Trovo x₁ e x₂.
    4. Guardo la parabola e scelgo:

    > 0

    Fuori dalle soluzioni

    x < x₁ oppure x > x₂

    < 0

    Dentro le soluzioni

    x₁ < x < x₂

    Ripasso · parte 2

    Esempio: x² − x − 6 > 0

    Risolvo l'equazione

    Δ = 1 + 24 = 25

    x = 1 ± 52

    x₁ = −2    x₂ = 3

    Scegli il simbolo

     

    Con ≥ e ≤ anche −2 e 3 vanno bene: lì la parabola vale 0.

    Ripasso · parte 2

    Casi speciali: Δ = 0 e Δ < 0

    Δ < 0 · non tocca l'asse

    x² + 1

    > 0 → sempre vera
    Tutti i numeri vanno bene.

    < 0 → mai vera
    Nessun numero va bene.

    Δ = 0 · tocca l'asse in un punto

    x² − 4x + 4 = (x − 2)²

    > 0 → tutti tranne 2: x ≠ 2

    ≥ 0 → sempre vera

    < 0 → mai vera

    ≤ 0 → solo x = 2

    Ripasso · parte 3

    Disequazioni fratte

    x − 1x + 2 ≥ 0

    Non posso moltiplicare per x + 2.

    Non so se x + 2 è positivo o negativo.

    Quindi non so se devo girare il verso.

    Allora guardo i segni

    ++ = +

    −− = +

    +− = −

    −+ = −

    Segni uguali: +. Segni diversi: −.

    Ripasso · parte 3

    Disequazioni fratte: il metodo

    1. Porto tutto a sinistra e faccio una sola frazione. A destra resta 0.
    2. Studio il numeratore: N > 0
      Se c'è ≥ o ≤, scrivo N ≥ 0.
    3. Studio il denominatore: D > 0
      Sempre con >. Il denominatore non può fare 0.
    4. Faccio la tabella dei segni.
      Linea piena: +. Linea tratteggiata: −.
    5. Scelgo le zone giuste.
      > 0 → zone +    < 0 → zone −

    I numeri che fanno 0 il denominatore non sono mai soluzione. Pallino vuoto.

    Ripasso · parte 3

    Esempio: x − 1x + 2 ≥ 0

    N ≥ 0:   x − 1 ≥ 0 → x ≥ 1

    D > 0:   x + 2 > 0 → x > −2

    Cerco ≥ 0: prendo le zone +.

    x < −2 oppure x ≥ 1

    1 va bene: lì la frazione vale 0, e 0 ≥ 0.

    −2 no: lì il denominatore vale 0.

    I sistemi

    Che cos'è un sistema?

    Un sistema è un gruppo di disequazioni.

    Si scrivono una sotto l'altra, con una graffa.

    x > 1
    x < 4

    La soluzione sono i numeri che vanno bene per tutte le disequazioni.

    Se un numero va bene solo per una, non è soluzione.

    Esempio

    Per giocare a calcio servono il pallone e le scarpe.

    Solo il pallone non basta. Solo le scarpe non bastano. Nel sistema servono tutte le disequazioni.

    I sistemi

    Prova un numero

    x > 1
    x < 4

    Sposta il cursore. Guarda quali disequazioni sono vere.

    Il numero 5 è soluzione del sistema?

    I sistemi

    Attenzione: due grafici diversi

    Tabella dei segni

    per una fratta

    Una disequazione sola.

    Le linee sono i segni + e −.

    I segni si moltiplicano.

    Grafico del sistema

    per un sistema

    Più disequazioni.

    Le linee dicono dove è vera.

    Cerco dove ci sono tutte le linee.

    Nel sistema i segni non si moltiplicano.

    I sistemi

    Il metodo in 4 passi

    1. Risolvo ogni disequazione da sola, fino alla fine.
      Come se le altre non ci fossero.
    2. Metto tutti i numeri trovati su una retta, in ordine.
    3. Faccio una riga per ogni disequazione.
      Linea piena dove la disequazione è vera.
    4. La soluzione è dove tutte le righe sono piene.
    I sistemi · esempio 1

    Esempio 1

    2x − 2 > 0
    8 − 2x > 0

    1ª2x > 2 → x > 1

    2ª−2x > −8 → x < 4

    Nella 2ª divido per −2: giro il verso.

    Soluzione: 1 < x < 4

    I sistemi

    Come si scrive la soluzione

    Pallino vuoto o pieno?

    ○ vuoto: il numero non va bene.
    >   <

    ● pieno: il numero va bene.
    ≥   ≤

    Una zona → 1 < x ≤ 4

    Due zone → si usa oppure: x < −2 oppure x > 3

    Nessuna zona piena

    → Il sistema è impossibile.
    Nessun numero va bene.

    Tutta la retta piena

    → Sempre vero.
    Tutti i numeri vanno bene.

    Un numero è soluzione solo se è pieno in tutte le righe. Basta un pallino vuoto e quel numero non va bene.

    I sistemi · esempio 2

    Esempio 2

    x² − 4 < 0
    2x − 1 ≥ 0

    1ªx² = 4 → x = −2, x = 2
    < 0: dentro. −2 < x < 2

    2ª2x ≥ 1 → x ≥ ½

    Soluzione: ½ ≤ x < 2

    I sistemi · esempio 3

    Esempio 3 · risolvo le due disequazioni

    x² − 9 ≥ 0
    x − 5x + 1 < 0

    1ªx² = 9 → x = −3, x = 3   ≥ 0: fuori, con i numeri.
    x ≤ −3 oppure x ≥ 3

    2ªÈ una fratta. N > 0: x > 5    D > 0: x > −1

    < 0: prendo la zona −. −1 < x < 5

    I sistemi · esempio 3

    Esempio 3 · il grafico del sistema

    1ªx ≤ −3 oppure x ≥ 3

    2ª−1 < x < 5

    I numeri in ordine: −3, −1, 3, 5.

    Soluzione: 3 ≤ x < 5

    I sistemi

    Casi speciali

    Una è sempre vera

    x² + 1 > 0

    La sua riga è tutta piena. Non toglie niente.

    Una è mai vera

    x² + 1 < 0

    Tutto il sistema è impossibile. Non serve il grafico.

    Le righe non si incontrano

    x > 3
    x² − 1 < 0  →  −1 < x < 1

    Nessuna zona con tutte le righe piene: il sistema è impossibile.

    I sistemi

    Errori da evitare

    1. Nel sistema non moltiplico i segni. Cerco dove sono vere tutte.
    2. Moltiplico o divido per un negativo → giro il verso.
    3. Nella fratta non tolgo il denominatore. Studio i segni.
    4. I numeri del denominatore hanno sempre il pallino vuoto.
    5. Risolvo ogni disequazione fino alla fine, poi faccio il grafico.
    6. Alla fine controllo ogni pallino: pieno o vuoto?
