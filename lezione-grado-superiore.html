Le equazioni di grado
superiore al secondo

x³ − 2x² − 5x + 6 = 0

Alla fine della lezione sapremo risolvere questo.

Le parti della lezione

    Ripasso · parte 1

    Il prodotto che fa zero

    Moltiplico due numeri e viene 0.

    Allora almeno uno dei due è 0.

    7 · 0 = 0    0 · 5 = 0

    A · B = 0

    vuol dire A = 0 oppure B = 0.

    Perché ci serve?

    Un'equazione grande, scritta come prodotto, si spezza in equazioni piccole.

    (x − 3) · (x + 1) = 0

    x − 3 = 0 → x = 3

    oppure

    x + 1 = 0 → x = −1

    Funziona solo con lo 0. Se il prodotto fa 6, i numeri possono essere 2 · 3, 1 · 6, 12 · 0,5… non so niente.

    Ripasso · parte 1

    Le equazioni di 2° grado

    ax² + bx + c = 0

    Δ = b² − 4ac     x = −b ± √Δ2a

    Δ > 0

    Due soluzioni.

    Δ = 0

    Una soluzione (due uguali).

    Δ < 0

    Nessuna soluzione.

    x² − x − 6 = 0

    Δ = 1 + 24 = 25

    x = 1 ± 52 → x = 3, x = −2

    Il 2° grado lo sappiamo risolvere sempre. Il nostro obiettivo: arrivare a pezzi di 1° e 2° grado.

    Ripasso · parte 1

    Le scomposizioni che servono

    Scomporre vuol dire scrivere come prodotto.

    Raccoglimento

    x³ − 5x = x(x² − 5)

    Differenza di quadrati

    x² − 9 = (x − 3)(x + 3)

    Differenza di cubi

    x³ − 8 = (x − 2)(x² + 2x + 4)

    Somma di cubi

    x³ + 1 = (x + 1)(x² − x + 1)

    Somma di quadrati: x² + 4 non si scompone. E x² + 4 = 0 non ha soluzioni: x² non è mai negativo.

    L'idea · parte 2

    Il grado e le soluzioni

    Il grado è l'esponente più alto della x.

    x³ − 4x = 0 → grado 3

    x⁴ − 5x² + 4 = 0 → grado 4

    Grado 3: al massimo 3 soluzioni.
    Grado 4: al massimo 4. E così via.

    L'idea · parte 2

    Il metodo in 4 passi

    1. Porto tutto a sinistra. A destra resta = 0.
    2. Scompongo: scrivo il polinomio come prodotto di pezzi piccoli.
      Pezzi di 1° grado e di 2° grado.
    3. Metto ogni pezzo = 0 e lo risolvo.
    4. Scrivo tutte le soluzioni trovate.

    x³ − 4x = 0

    x · (x − 2) · (x + 2) = 0

    x = 0   x = 2   x = −2

    L'idea · parte 2

    Non si divide per x

    Sbagliato

    x³ = 9x

    divido per x: x² = 9

    x = ±3

    Ho perso x = 0.

    Giusto

    x³ − 9x = 0

    x(x² − 9) = 0

    x = 0, x = ±3

    3 soluzioni.

    Perché?

    Provo x = 0: 0³ = 9 · 0 → 0 = 0. Vero! Dividendo per x faccio finta che x non sia 0. Invece può esserlo. Allora porto tutto a sinistra e raccolgo.

    I casi · parte 3

    Caso 1: raccolgo la x

    Quando lo uso: manca il termine noto (il numero senza x).

    x³ − 4x = 0

    x(x² − 4) = 0

    x = 0

    x² − 4 = 0 → x² = 4 → x = ±2

    Il pezzo di 2° grado senza la x di 1° grado si risolve senza Δ:

    x² = 4 → x = +2 oppure x = −2

    Tutti e due: (+2)² = 4 e (−2)² = 4.

    Soluzioni: x = 0, x = 2, x = −2

    I casi · parte 3

    Caso 1: raccolgo x²

    x⁴ − 9x² = 0

    x²(x² − 9) = 0

    x² = 0 → x = 0 (conta due volte)

    x² − 9 = 0 → x = ±3

    Soluzioni: x = 0, x = 3, x = −3

    Raccolgo la x con l'esponente più piccolo. In x⁴ − 9x² c'è x² in tutti e due i termini: raccolgo x².

    I casi · parte 3

    Caso 2: prodotti notevoli

    Quando lo uso: ci sono solo due termini, ed entrambi sono quadrati o cubi.

    Differenza di quadrati

    x⁴ − 16 = 0

    (x² − 4)(x² + 4) = 0

    x² = 4 → x = ±2

    x² = −4 → impossibile

    Soluzioni: x = 2, x = −2

    Differenza di cubi

    x³ − 8 = 0

    (x − 2)(x² + 2x + 4) = 0

    x = 2

    Δ = 4 − 16 < 0 → nessuna

    Soluzione: x = 2

    Un pezzo può non avere soluzioni. Non è un errore: lo scrivo e vado avanti con gli altri pezzi.

    I casi · parte 3

    Caso 3: raccolgo a coppie

    Quando lo uso: 4 termini che, presi a coppie, hanno un pezzo uguale.

    x³ + 2x² − 9x − 18 = 0

    x²(x + 2) − 9(x + 2) = 0

    Le due coppie hanno lo stesso pezzo (x + 2): lo raccolgo.

    (x + 2)(x² − 9) = 0

    x + 2 = 0 → x = −2

    x² − 9 = 0 → x = ±3

    Soluzioni: x = −2, x = 3, x = −3

    Attenzione al segno: − 9x − 18 = −9(x + 2). Con il − davanti, dentro la parentesi i segni si girano.

    I casi · parte 3

    Caso 4: Ruffini

    Quando lo uso: non riesco a raccogliere né a usare i prodotti notevoli.

    x³ − 6x² + 11x − 6 = 0

    Se un numero fa diventare il polinomio 0, allora (x − numero) è un suo pezzo.

    Dove lo cerco? Tra i divisori del termine noto (il numero senza x), con il + e con il −.

    −6 → ±1, ±2, ±3, ±6

    Prova i divisori

    Clicca un numero: lo metto al posto della x.

    I casi · parte 3

    Caso 4: la tabella

    P(1) = 0, quindi divido per (x − 1).

    1. In alto i coefficienti. A sinistra il 1.
    2. Abbasso il primo: 1.
    3. Moltiplico per 1 e scrivo sotto il −6. Sommo: −6 + 1 = −5.
    4. Ripeto: 11 − 5 = 6; −6 + 6 = 0.

    (x − 1)(x² − 5x + 6) = 0

    x − 1 = 0 → x = 1

    Δ = 25 − 24 = 1

    x = 5 ± 12 → x = 3, x = 2

    Soluzioni: x = 1, x = 2, x = 3

    I casi · parte 3

    Caso 5: xⁿ = numero

    Si chiamano binomie: solo due termini, la x con un esponente e un numero.

    x⁴ = 81

    Esponente pari, numero positivo: due soluzioni.

    x = ±3

    x³ = −27

    Esponente dispari: una soluzione, con lo stesso segno.

    x = −3

    x⁴ = −16

    Esponente pari, numero negativo.

    impossibile

    Perché?

    (−3)⁴ = (−3)(−3)(−3)(−3) = 81: con un numero pari di meno, il segno sparisce. Quindi x⁴ non è mai negativo.
    (−3)³ = −27: con un numero dispari di meno, il − resta.

    I casi · parte 3

    Caso 6: x⁴ e x²

    Si chiamano biquadratiche: ci sono solo x⁴, x² e un numero.

    x⁴ − 5x² + 4 = 0

    x⁴ è (x²)². Chiamo t = x²:

    t² − 5t + 4 = 0  → 2° grado!

    Δ = 25 − 16 = 9

    t = 5 ± 32 → t = 4, t = 1

    Non mi fermo a t! Torno alla x: x² = t.

    x² = 4 → x = ±2

    x² = 1 → x = ±1

    Soluzioni: x = ±1, x = ±2 (4 soluzioni)

    I casi · parte 3

    Caso 6: t negativo

    x⁴ + 3x² − 4 = 0

    Chiamo t = x²:

    t² + 3t − 4 = 0

    Δ = 9 + 16 = 25

    t = −3 ± 52 → t = 1, t = −4

    x² = 1 → x = ±1

    x² = −4 → impossibile

    Soluzioni: x = 1, x = −1

    t = x² non può essere negativo. Se t viene negativo, quel pezzo non dà soluzioni.

    I casi · parte 3

    Caso 7: x⁶ e x³

    Si chiamano trinomie. Stessa idea delle biquadratiche: un esponente è il doppio dell'altro.

    x⁶ − 9x³ + 8 = 0

    x⁶ è (x³)². Chiamo t = x³:

    t² − 9t + 8 = 0

    Δ = 81 − 32 = 49

    t = 9 ± 72 → t = 8, t = 1

    x³ = 8 → x = 2

    x³ = 1 → x = 1

    Soluzioni: x = 1, x = 2

    x³ ha esponente dispari: una sola soluzione, niente ±. E va bene anche se t è negativo: x³ = −8 → x = −2.

    I casi · parte 3

    Come scelgo il metodo

    Dopo aver portato tutto a sinistra, mi faccio queste domande, in ordine.

    1. Manca il numero senza x? → raccolgo la x.
    2. Ci sono solo due termini? → xⁿ = numero o prodotto notevole.
    3. Ci sono solo x⁴, x² e un numero? → t = x².
      Con x⁶, x³ e un numero: t = x³.
    4. 4 termini con coppie simili? → raccolgo a coppie.
    5. Niente di tutto questo? → Ruffini, con i divisori del numero senza x.

    Dopo un passo, ogni pezzo di 3° grado o più si scompone ancora, con le stesse domande.

    I casi · parte 3

    Errori da evitare

    1. Non divido per x: perdo x = 0. Porto tutto a sinistra e raccolgo.
    2. x² = 9 dà due soluzioni: x = 3 e x = −3.
    3. Con t = x² non mi fermo a t: torno alla x.
    4. x² = numero negativo → impossibile. x³ = numero negativo → va bene.
    5. In Ruffini, se manca un termine, scrivo 0 al suo posto.
      x³ − 7x + 6 → 1, 0, −7, 6.
    6. Alla fine scrivo le soluzioni di tutti i pezzi.
